# EDyMN - Ecuaciones Diferenciales y Métodos Numéricos

Este repositorio almacena las sesiones de laboratorio de la asignatura **Ecuaciones Diferenciales y Métodos Numéricos (EDyMN)**.

## Propósito

Reunir en un solo lugar el material de laboratorio de la asignatura, organizado por semanas, con los ejercicios **completamente resueltos**.

## Contenido del repositorio

Cada archivo de laboratorio está en formato Jupyter Notebook (`.ipynb`) y corresponde a una sesión específica.

Estructura actual:

- `Semana_1.ipynb`
- `Semana_2.ipynb`

A medida que avance el curso, se agregarán nuevas sesiones con su resolución completa.

## Uso

1. Clona este repositorio.
2. Abre los notebooks con Jupyter Notebook o JupyterLab.
3. Revisa el desarrollo paso a paso de cada sesión y ejecuta las celdas si deseas reproducir los resultados.

## Enfoque de las sesiones

Las sesiones incluyen trabajo práctico orientado a:

- análisis y resolución de problemas de ecuaciones diferenciales,
- apoyo computacional con Python,
- métodos numéricos y representación gráfica de resultados.
